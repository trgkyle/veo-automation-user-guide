# 🎬 VEO Automation v3.1.7 - Google Flow AI VEO 自动化 [![English](https://img.shields.io/badge/English-blue)](README.md) [![Tiếng Việt](https://img.shields.io/badge/Tiếng%20Việt-green)](README_vi.md)

**VEO Automation** 是一个强大的 Chrome 扩展程序，可自动化 Google Flow AI VEO3 上的批量视频和图像生成。同时处理多个提示词，配置您的工作流程，并轻松自动下载生成的内容。

-----

## ✨ 主要功能

* **🚀 队列支持：** 将多个提示词添加到等待列表，而不是手动逐个操作。工具将自动逐个处理任务。
* **🧩 工作流（可视化拖放编辑器）：** 在画布上连接提示词、图片和生成节点——例如先生成图片，再自动用这些图片生成视频。可保存多个工作流，运行单个节点或全部运行，并以文件导入/导出。
* **📝 文本转视频：** 支持导入包含数百个提示词的 `.txt`、`.xlsx` 或 `.csv` 文件，从文本批量创建视频。
* **🖼️ 帧转视频：** 使用静态图片并添加自动运动效果。支持为每个提示词仅使用开始帧或同时使用开始帧和结束帧。
* **🎨 组件化视频：** 将 UI 组件、界面元素或角色图片动画化为视频。支持根据文件名自动匹配角色图片。
* **🖼️ 文本转图片：** 从文本描述生成图片。
* **🔄 图片转图片：** 使用 AI 和文本提示词转换和增强图片。
* **🤖 智能体自动化：** 使用高级智能体控制与 Google Flow AI 智能体合作自动执行任务。
* **📂 从电子表格导入：** 直接从电子表格文件（`.xlsx` 或 `.csv`）导入提示词列表，支持工作表与列的预览选择。
* **💾 自动下载：** 渲染完成后立即自动将视频（720p、1080p、4K）和图片（1k、2k、4k）保存到您的计算机。支持按项目名称组织文件夹。
* **🛡️ 重试机制：** 遇到网络错误或 Google 创建错误时自动重试（可自定义多达 20 次重试）。
* **🌐 多语言界面：** 支持 20 种语言，包括英文、中文、越南语等。

## 📖 使用指南

### 开始使用

1. **导航到 Google Flow**
   - 打开 [Google Labs Flow](https://labs.google/fx/tools/flow)
   - 扩展程序仅在 Flow 项目页面上工作。

2. **打开扩展程序**
   - 点击 Chrome 工具栏中的扩展程序图标并固定，以便后续快速使用。

3. **选择模式**
   - 在控制标签页中从 6 种生成模式中选择。

---

### 1. 文本转视频模式

1. 在控制标签页中选择 **文本转视频** 模式。
2. 在输入框中输入提示词（每个提示词用空行分隔）或点击 **上传 .txt** 或 **上传 .xlsx / .csv** 按钮上传提示词列表。
3. 配置时长设置（可选择 4s、6s、8s、10s 或合并连接模式）。
4. 点击 **运行** 开始批量处理。

**提示词示例：**
```
平静海洋上宁静的日落，轻柔的波浪。
相机慢慢扫过地平线。

夜晚繁华的城市街道，霓虹灯闪烁。
汽车和行人在场景中穿行。
```

---

### 2. 帧转视频模式（原图片转视频）

1. 选择 **帧转视频** 模式。
2. 点击上传区域上传图片（支持一次选择多张图片）。
3. 为每张图片输入提示词（用空行分隔）。
4. 在设置中，配置每个提示词是仅使用开始帧还是同时使用开始帧和结束帧。
5. 点击 **运行** 进行处理。

---

### 3. 组件化视频模式（原组件转视频）

1. 选择 **组件化视频** 模式。
2. 上传组件或角色图片。
3. 输入描述动画的提示词。
4. **自动添加上传的角色图片**（可选）：启用后，系统将根据文件名自动匹配角色图片并添加到提示词中。
5. **自动添加角色（Google Flow 功能 ⭐）**：当提示词中提及项目角色名称时，自动选择对应角色（点击 **扫描角色** 按钮同步角色）。
6. **按说话者自动添加语音**：当提示词中提到说话者名称时，自动选择对应的语音。
7. 点击 **运行** 生成。

---

### 4. 文本转图片模式

1. 选择 **文本转图片** 模式。
2. 输入详细的图片描述（每行一个或空行分隔）。
3. 在设置中配置宽高比和图片模型。
4. 点击 **运行** 生成图片。

---

### 5. 图片转图片模式

1. 选择 **图片转图片** 模式。
2. 上传源图片。
3. 输入转换提示词。
4. **自动添加上传的角色图片**（可选）：基于文件名将角色图片自动匹配并引入到提示词。
5. 点击 **运行** 开始转换。

---

### 6. 智能体自动化模式

1. 选择 **智能体自动化** 模式。
2. 输入描述智能体任务的提示词。
3. 支持角色控制（Google Flow 功能 ⭐）和基于提示词提及的按说话人自动添加语音。
4. 点击 **运行** 执行智能体任务。

---

### 📁 文件保存与命名（适用于所有模式）

在每个模式的提示词/图片输入框下方，您可以配置文件的保存方式：
* **保存至文件夹**：在 Chrome 默认下载文件夹中指定一个子文件夹名称（例如：`project-1`）以自动分类存储生成的文件。
* **自动更改文件名**：开启后，扩展程序将自动使用清晰的前缀和项目目录路径重命名下载的文件；关闭后则保留浏览器默认的命名行为。

### 队列管理

* 在 **Prompt 队列** 部分查看待处理任务列表。
* 点击 **移除** 丢弃多余任务，或点击 **停止** 停止当前运行的整个队列。
* 实时显示提示词之间的等待时间倒计时。

### 🧩 工作流（可视化拖放编辑器）

工作流是用于多步骤流程的可视化拖放编辑器——例如：先生成几张图片，再用这些图片生成视频，然后用另一个提示词延续每个视频。它在独立窗口中打开，并在您已打开的 Google Flow 标签页上运行。

#### 打开工作流

* 在控制标签页中点击 **工作流**（最下面一排按钮）。
* 已在侧边面板输入提示词或上传图片？将鼠标悬停在 **工作流** 上并点击 **转换为工作流**：提示词、每个提示词的模式和图片都会变成工作流中的节点，可直接运行。

#### 界面

| 区域 | 内容 |
| :--- | :--- |
| **左侧** | **节点**（点击或拖到画布上）和 **我的工作流**（已保存的工作流列表） |
| **顶部栏** | 画布工具：撤销/重做、**自动排列**、适应视图、**示例**、清空。右侧：**详情** 按钮、**快捷键** 和 Google Flow 标签页状态 |
| **画布** | 您的节点。左上角：**全部运行**（运行时还有 **停止**）和 **开启后台模式** |

**详情** 按钮提示需要注意的情况：有问题阻止运行时显示红色/黄色的 **问题 (n)**，生成时显示 **运行中 3/8**。点击可打开面板，查看问题（点击问题跳到对应节点）、进度、运行计划及所用设置。

#### 节点

| 节点 | 作用 |
| :--- | :--- |
| **输入提示词** | 一个或多个提示词，用 **空行** 分隔 |
| **上传图片** | 您的图片（可直接把文件拖到节点上）。悬停图片：🔍 放大查看，✕ 删除，拖动角上的手柄可调整顺序。顺序（或排序菜单）决定每个提示词使用哪张图片 |
| **生成图片** | 文本生成图片；连接图片后为图片生成图片。选项：**每个提示词的图片模式**、**每个提示词的最大输入图片数**、**自动添加角色图片** |
| **生成视频** | 文本生成视频；连接图片后为 **帧图生成视频** / **素材生成视频**。选项：**每个提示词的视频模式**、每个提示词的图片数（与侧边面板设置共用）、**自动添加角色图片**（素材生成视频） |

生成节点会根据第一个提示词自动命名（`image_…` / `video_…`）。每行提示词都会显示它将使用的图片，方便运行前检查。预览区域采用设置中的 **宽高比**（9:16 的节点更窄更高）。

**帧图生成视频** 可以只用起始帧，也可以用 **起始帧和结束帧**（与侧边面板设置共用）。使用起始帧和结束帧时，每个提示词按顺序使用 2 张图片（延续上一个视频的提示词使用 1 张）；图片不够时，节点会显示警告且无法运行。

#### 连接节点

从节点右侧的圆形连接点拖出，**放到另一个节点的任意位置**——会自动选择合适的输入口。拖动时，可以连接的节点会高亮。

| 从 | 到 | 含义 |
| :--- | :--- | :--- |
| 输入提示词 | 生成图片 / 生成视频 | 要生成的提示词 |
| 上传图片 | 生成图片 / 生成视频 | 参考图、起始帧或素材 |
| 生成图片 | 生成图片 / 生成视频 | **生成的图片** 作为该节点的输入（图片就绪后才运行） |
| 生成视频 — **最后一帧** 输出 | 生成视频 | 后一个视频 **从前一个视频的最后一帧继续** |
| 生成视频 — **最后一帧** 输出 | 生成图片 | 每个视频的 **最后一帧** 作为输入图片（视频就绪后才运行） |

#### 运行

* **全部运行**（左上角，或 `Ctrl/⌘ + Enter`）按正确顺序运行整个工作流：需要生成图片的节点会在图片就绪后自动开始。
* 如果 **全部运行** 不可用，顶部栏会显示 **问题 (n)**：点击查看需要修复的内容。
* 每个生成节点都有自己的 **运行** 按钮，只运行该节点。在其依赖的节点完成之前按钮不可用（悬停可查看原因）。
* **停止** 取消仍在运行的任务。
* 运行时，连向正在生成的节点的连线会发光并流动，让您看到工作流进行到哪一步。

> ⚠️ **Google Flow 标签页不可见时 Chrome 会暂停它**（例如工作流窗口全屏遮住它时）。点击 **开启后台模式**（工作流中 **全部运行** 按钮下方，或侧边面板中），然后在 Chrome 的对话框中选择 Google Flow 标签页。这会共享 Google Flow 标签页（不会录制或发送到任何地方），让它在其他窗口后面继续生成。绿色的 **后台运行中** 标识表示已开启；点击 ✕ 关闭。

#### 结果

结果直接显示在生成节点中。悬停结果：🔍 放大查看，✕ 删除（橡皮擦按钮清除该节点的全部结果）。悬停时视频自动播放。文件仍会照常下载。

下一个节点使用 **每个提示词的第一个结果**。要换成别的结果，拖动结果左上角的手柄放到另一个结果上即可交换位置（图片和视频均可）。

#### 管理工作流

在左侧的 **我的工作流** 中：**新建**、**导入**，以及每个工作流的 **⋯** 菜单——**重命名**（或双击名称）、**复制**、**导出**、**删除**。所有更改都会自动保存。

* **导出** 会下载一个 `.json` 文件。文件开头有 `//` 注释行，描述所有节点、属性和连接方式，因此您可以把文件交给 AI 助手，让它编写新的工作流。导入时会自动去掉这些注释行。
* 用 **导入** 按钮导入文件，或直接 **把 `.json` 文件拖到画布上**。

#### 编辑快捷键

点击顶部栏的 **快捷键**（或按 `?`）查看全部快捷键。

| 操作 | 按键 |
| :--- | :--- |
| 撤销 / 重做 | `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` |
| 复制 / 剪切 / 粘贴节点（也可粘贴到其他工作流） | `Ctrl/⌘ + C / X / V` |
| 复制一份所选节点 | `Ctrl/⌘ + D` |
| 全选 / 加选 / 框选 | `Ctrl/⌘ + A` / `Ctrl/⌘ + 点击` / `Shift + 拖动` |
| 自动排列 | `Shift + A` |
| 删除所选 | `Delete` |
| 全部运行 / 后台运行 | `Ctrl/⌘ + Enter` / `Ctrl/⌘ + Shift + Enter` |

## ⚙️ 设置配置

访问 **设置** 标签页进行自定义：

### 常规设置
- **默认模式**：设置您常用的生成模式，以便在打开扩展程序时自动为您选择。
- **默认宽高比**：选择 16:9、9:16、1:1、3:4 或 4:3。
- **每个 prompt 的输出数量**：设置每个提示词要创建的数量（1-4 个图像/视频）。
- **并发 Prompt**：同时处理 1-6 个提示词（注意：合并连接和智能体模式限制 1 个并发，以防任务冲突）。
- **随机等待**：设置提示词提交之间的等待时间，以避免请求速率限制。

### 模型选择
- **模型 (视频)**：从 Veo 3.1 或 Veo 2 变体中选择，包括 `Veo 3.1 - Lite`、`Veo 3.1 - Lite [Lower Priority]`、`Veo 3.1 - Fast`、`Veo 3.1 - Quality` 和 `Omni Flash`。
- **图像模型**：选择用于文本转图像生成的 AI 模型，包括 `Nano Banana 2 Lite`、`Nano Banana Pro` 和 `Nano Banana 2`。

### 模式特定选项
- **默认视频选项**：可选择 4秒、6秒、8秒、10秒或合并模式（`4秒/6秒/8秒/10秒（合并）`）。
  > [!NOTE]
  > 使用合并连接时，当前的提示词与后续的提示词将被合成为单个视频。序列中的最后一个提示词始终默认使用标准持续时间（非合并）。
- **默认图片模式选项**：设定为 新图片 或 上一张图片（复用前一个提示词生成的图片作为输入）。
- **最大输入图片/视频**：为帧转视频、组件化视频和图片转图片模式配置输入资产的最大限制。
- **角色控制设置 (Character Control Settings)**：配置**默认角色** (Default characters) 并启用/禁用角色控制。
- **声音说话者设置 (Voice Speaker Settings)**：在提示词没有提及特定说话者时设置**默认说话者** (Default speaker)。

### 下载和高级设置
- **自动下载质量 (视频)**：选择自动下载的视频分辨率（720p, 1080p, 4K）。1080p/4K 等分辨率需要 Ultra/Pro 方案。
- **自动下载质量 (图片)**：选择自动下载的图片分辨率（1k, 2k, 4k）。4k 分辨率需要 Ultra 方案。
- **失败时最大重试次数**：设置生成失败时的重试次数（1-20次）。
- **语言**：在 20 种支持的语言中选择（英文、中文、越南语、韩文、西班牙文、日文等）。

## 💡 提示和最佳实践

1. **避免请求限制（Rate Limit）**
   - 高峰期建议设置约 2-3 个并发提示词。
   - 适当将随机等待延迟调整为 30 秒或更长。

2. **图片命名规则**
   - 自动匹配时，图片命名保持逻辑性（例如：`hero_pose.png`），并在提示词中提及完全一致的文件名。

3. **修复“异常活动”错误**
   - 在开启自动化运行前，请确保您能够手动在 Google Flow 上连续成功提交至少 3 个提示词且不出现任何错误。

## 🔧 故障排除

| 问题 | 原因和解决方案 |
| --- | --- |
| **扩展程序不工作** | 确保您在 Google Flow 项目页面上 (`labs.google/fx/tools/flow/project/...`)。 |
| **异常活动 / 验证错误** | 1. 点击控制标签页中的 **修复错误**（清除缓存）按钮。<br>2. 尝试新建一个 Flow 项目。<br>3. 尝试使用全新的浏览器配置文件。<br>4. 通过手动创建测试账号是否已被 Google 标记。 |
| **视频/图片不下载** | 关闭 Chrome 的下载弹窗询问：Chrome 设置 -> 下载 -> **关闭** *"下载前询问每个文件的保存位置"*。 |
| **“政策错误”** | 提示词或图片违反了 Google 内容政策。工具将自动跳过并处理下一个提示词。 |
| **屏幕缩小** | 这是工具定位 UI 按钮的自动化缩放功能。请勿在运行时手动调整浏览器缩放级别。 |
| **工作流：结果一直停在“生成中”** | Chrome 暂停了被遮住的 Google Flow 标签页。开启 **开启后台模式**（或 **后台运行**），或保持 Google Flow 标签页可见。 |
| **工作流：某个节点的运行按钮不可用** | 将鼠标悬停在按钮上：先运行它依赖的节点，或修复提示的问题（例如未连接提示词）。 |
| **工作流：全部运行不可用** | 点击顶部栏的 **问题 (n)** 查看需要修复的内容；点击某个问题可跳到对应节点。 |
| **工作流：“未找到 Google Flow 标签页”** | 在标签页中打开 [Google Flow](https://labs.google/fx/tools/flow)（顶部栏的绿点表示已连接）。 |
